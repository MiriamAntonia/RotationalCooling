CoolingSimulation.ipynb
- Simulation of the cooling dynamics using MC methods. 
- Needs a .pkl file as an input with the excitation probabilities after one pulse for the diferent transitions. These are generated in the Off-Res_Excitation simulations.

Dependencies_Plotting.ipynb
- For plotting the dependence of the cooling efficiency on the resolution and the detuning between Q-branch and the spectral cut.
